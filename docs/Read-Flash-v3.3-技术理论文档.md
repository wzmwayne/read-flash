# Read-Flash 技术理论文档

**版本**：3.3
**性质**：终端风格、书页模型的系统设计规范
**定位**：面向极低端设备与跨平台场景的纯文本阅读器

> 本文档是**基线规范**。其修订补丁见 [Read-Flash v3.4 修订条文](Read-Flash-v3.4-修订条文.md)，评审过程见 [设计评审提问清单](Read-Flash-v3.3-设计评审提问.md)。

## 1. 核心原则

### 1.1 二进制优先

P1：源文件以二进制模式打开，逐字节读取，不做文本模式转换。

P2：源文件行分隔符仅识别 `\n`（0x0A）。`\r`（0x0D）视为普通字节。

P3：存储文件采用换行分隔的二进制格式，每行定长，二进制读取，文本可调试。

P4：所有内部计算以整数或定点数进行，不使用浮点数参与索引和定位。

P5：字符宽度以定点数表示，排版宽度计算为整数加法。

### 1.2 不变量

I1：源文件行号与文件物理 `\n` 一一对应。

I2：任意时刻内存中至多存在一个页面的排版数据。

I3：阅读进度仅由源文件行号决定，偏移几行不影响体验。

I4：排版结果不持久化，仅索引与进度落盘。

I5：所有界面共用同一套排版、渲染、触摸逻辑。

I6：顶栏始终可见，不可隐藏。

I7：翻页行是真实的一行，占据独立显示行，不浮动。

I8：只有阅读界面支持点击正文区左右二分之一翻页，其他界面翻页仅通过底栏。

I9：翻页键有可用和不可用两种状态，不可用时点击无响应。

## 2. 界面模型：一切皆书

### 2.1 书页统一模型

整个应用是一个书树。每个界面是一本书，导航是翻页和返回。

```
书库
 ├─ 阅读《三体》
 ├─ 阅读《红楼梦》
 ├─ 设置
 │    └─ 调试
 └─ ...
```

没有页面类型，只有书。 所有书共用同一套渲染管线、触摸逻辑、排版引擎。

### 2.2 界面结构

每本书由三部分构成：

```
┌─────────────────────────────┐
│ < 标题                       │  ← 顶栏：固定一行，始终可见
├─────────────────────────────┤
│                             │
│         正文区               │  ← 书的内容，可滚动翻页
│                             │
│                             │
├─────────────────────────────┤
│ <                         > │  ← 翻页行：真实一行，固定底部
└─────────────────────────────┘
```

顶栏：左侧 `<` 返回，右侧标题。固定，不滚动，不隐藏。

正文区：书的内容。支持标题、按钮、单选、多选、换页符。

翻页行：固定占据一行显示行，底部对齐。左侧 `<`，右侧 `>`。空间充足时显示完整符号加间距，空间不足时只显示符号本身。

### 2.3 翻页键的可用与不可用

翻页行左右各有一个翻页键，每个键有可用和不可用两种状态。

| 键 | 可用条件 | 不可用条件 |
|---|---|---|
| `<` 上一页 | 当前页不是第一页 | 当前页是第一页 |
| `>` 下一页 | 当前页不是最后一页 | 当前页是最后一页（terminateReason = EOF） |

视觉区分：

| 状态 | 颜色 | 说明 |
|---|---|---|
| 可用 | 暗灰 #666666 | 正常显示，可点击 |
| 不可用 | 深灰 #333333 | 更暗，视觉上明显弱化 |

触摸行为：

- 可用：单击触发翻页。
- 不可用：单击无任何响应，不触发翻页，不触发其他动作。

状态更新：每次翻页后，根据新页的 PageState 重新计算两个翻页键的可用状态。

```
updatePagerState(state):
    canPrev = !(state.firstSourceLine == 1)
    canNext = !(state.terminateReason == EOF)
    renderPagerKey('<', canPrev)
    renderPagerKey('>', canNext)
```

边界情况：

| 情况 | `<` 状态 | `>` 状态 |
|---|---|---|
| 第一页 | 不可用 | 可用（除非只有一页） |
| 最后一页 | 可用 | 不可用 |
| 只有一页 | 不可用 | 不可用 |
| 空文件 | 不可用 | 不可用 |

### 2.4 翻页行是真实的一行

翻页行不是浮动在正文上的，而是界面布局中真实占据一个显示行的固定区域。它和顶栏一样，不参与正文滚动。

翻页行的内容：

```
<                         >
```

左对齐 `<`，右对齐 `>`。中间留空。

空间不足时：

- 正常：`<` 和 `>` 各有足够间距
- 紧凑：`<` 和 `>` 靠近边缘
- 极窄：只显示 `<` 和 `>` 符号，无额外空格

翻页行的触摸：点击翻页行左侧 `<` 区域触发上一页，点击右侧 `>` 区域触发下一页。点击中间不触发翻页。不可用状态下点击对应区域无响应。

### 2.5 翻页机制

阅读界面：

| 操作 | 效果 |
|---|---|
| 点击正文区左 1/2 | 上一页（若不可用则无响应） |
| 点击正文区右 1/2 | 下一页（若不可用则无响应） |
| 点击翻页行左端 `<` | 上一页（若不可用则无响应） |
| 点击翻页行右端 `>` | 下一页（若不可用则无响应） |

阅读界面正文区不区分中间区域，左右各占一半。因为阅读界面正文区没有可交互的按钮组件（只有正文），不需要为组件留出中间点击区。

其他界面（书库、设置、调试等）：

| 操作 | 效果 |
|---|---|
| 点击正文区 | 仅触发该位置的组件（按钮、单选、多选），不翻页 |
| 点击翻页行左端 `<` | 上一页（若不可用则无响应） |
| 点击翻页行右端 `>` | 下一页（若不可用则无响应） |

其他界面正文区包含大量可交互组件，如果点击正文区也翻页会与组件点击冲突。因此这些界面的翻页只通过底栏翻页行。

## 3. 终端视觉风格

### 3.1 调色板

固定一套，不切换主题：

| 颜色 | 值 | 用途 |
|---|---|---|
| 背景 | #000000 | 纯黑，OLED 省电 |
| 主前景 | #E0E0E0 | 正文 |
| 青色 | #00FFFF | 标题、书名、顶栏 |
| 绿色 | #00FF00 | 可点击按钮 `[xxx]` |
| 黄色 | #FFFF00 | 选中状态 `(>)` `(+)` |
| 红色 | #FF4444 | 删除、危险操作 |
| 暗灰 | #666666 | 可用翻页键、次要信息 |
| 深灰 | #333333 | 禁用按钮 `{xxx}`、不可用翻页键 |

### 3.2 颜色分配

| 语法 | 颜色 |
|---|---|
| 正文 | 白 |
| 标题 | 青 |
| 按钮 `[xxx]` | 绿 |
| 禁用按钮 `{xxx}` | 灰 |
| 单选选中 `(>)` | 黄 |
| 单选未选中 `( )` | 白 |
| 多选选中 `(+)` | 黄 |
| 多选未选中 `(-)` | 白 |
| 顶栏 `<` 和标题 | 青 |
| 书库选中行 `>` | 黄 |
| 进度百分比 | 灰 |
| 翻页键可用 `<` `>` | 暗灰 |
| 翻页键不可用 `<` `>` | 深灰 |

颜色是行的属性，一行内所有字符同色。

### 3.3 渲染

- 字形位图缓存为白色 alpha 通道。
- 渲染时用颜色值乘以 alpha，得到对应颜色。
- 帧缓冲黑底，每帧 memset 为 0 后贴字形。
- 无渐变、无阴影、无圆角。

## 5. 源文件模型

### 5.1 行号定义

- 行号从 1 开始。
- 第 i 行字节范围 `[start(i), end(i))`。
- 仅 `\n` 断行，`\r` 视为内容。
- 连续 `\n` 产生连续空行，不合并、不压缩。
- 末尾无 `\n` 时最后一行有效。
- 空文件行数为 0。

### 5.2 索引

自适应一级索引：

```
K = clamp(2^ceil(log2(L / 4096)), 256, 65536)
index1[j] = start(j × K + 1)
```

索引文件格式（换行分隔二进制）：

```
行1: 魔数+版本       8B + '\n'
行2: 总行数 L        8B + '\n'
行3: 文件字节数 S    8B + '\n'
行4: 文件采样哈希    8B + '\n'
行5: 索引间隔 K      4B + '\n'
行6: index1[0]       8B + '\n'
行7: index1[1]       8B + '\n'
...
```

### 5.3 定位算法

```
locate(line):
    j = (line - 1) >> log2(K)
    pos = index1[j]
    remaining = (line - 1) & (K - 1)
    while remaining > 0:
        pos = nextNewline(pos) + 1
        remaining--
    return pos
```

索引大小上限约 24KB，与文件行数解耦。

## 6. 排版计算

### 6.1 定点数宽度

| 字符类型 | 宽度 | 定点值 |
|---|---|---|
| CJK 全角 | 1/2 em | 0x8000 |
| 拉丁/半角 | 1/4 em | 0x4000 |
| 其他 | 0 | 0 |

行宽 = cjkCount × HALF_EM + halfWidthCount × QUARTER_EM，全程整数。

### 6.2 断行

逐字节扫描，按 CJK 首字节范围（0xE4–0xE9）判定全角，< 0x80 判定半角。累加宽度，超视口宽度则断行。

### 6.3 换页符

行内容为 `---`（恰好 3 字节）时判定为换页符。不产生显示行，当前页立即终止。

### 6.4 标题

行首 `#` 后跟空格，连续 `#` 数 1–3 判定为标题。字号放大，颜色青色。

## 7. 页面状态与翻页

### 7.1 PageState

```
PageState {
    firstSourceLine:   uint32    // 本页首显示行的源文件行号
    lastSourceLine:    uint32    // 本页末显示行的源文件行号
    displayLineCount:  uint16    // 显示行数
    terminateReason:   uint8     // 0=Filled, 1=Forced, 2=EOF
}
```

仅存于内存，翻页即弃。

### 7.2 下一页

- 若 Forced：从换页符下一行开始。
- 若 Filled：从末行续排位置开始。
- 若 EOF：无操作。

### 7.3 上一页

回溯重排：从当前页 firstSourceLine 往前估 V × 3 行，正向排版至累积显示行超过视口容量，从末尾截取一页。偏移几行不影响体验。

### 7.4 翻页键状态计算

```
canPrev = !(firstSourceLine == 1)
canNext = !(terminateReason == EOF)
```

- canPrev = false：`<` 显示为不可用（深灰），点击无响应。
- canNext = false：`>` 显示为不可用（深灰），点击无响应。

特殊情形：空文件（行数 0）时，canPrev = false，canNext = false，两个键均不可用。

## 8. 阅读进度

### 8.1 定义

```
ReadingProgress {
    sourceLine:       uint32    // 源文件行号
    totalSourceLines: uint32
    timestamp:        uint64
}
```

不记录行内偏移。偏移几行无所谓。

### 8.2 保存时机

翻页即保存。点下一页或上一页后，新页顶部行的源文件行号立即写入进度文件。无节流、无定时器、无退出保存。

### 8.3 跨页行

若某源文件行折为多个显示行且跨越两页，下一页顶部行号仍记该源文件行号。恢复时从该行行首排版，偏移几行可接受。

### 8.4 恢复

```
restore(progress):
    return layout(progress.sourceLine, viewportCapacity)
```

## 9. 存储格式

### 9.1 进度文件（.rfprog）

```
行1: 魔数+版本       8B + '\n'

行3: totalLines      4B + '\n'
行4: timestamp       8B + '\n'
行5: 校验和          4B + '\n'
```

约 30 字节。

### 9.2 设置文件（.rfset）

```
行1: 魔数+版本       8B + '\n'
行2: 字号            4B + '\n'
行3: 行距            4B + '\n'
行4: 校验和          4B + '\n'
```

约 20 字节。

### 9.3 索引文件（.rfidx）

见 5.2 节。约 24KB 上限。

### 9.4 字节序

统一小端。固定长度，无变长编码。

## 10. 设置

### 10.1 设置书

从书库点 `[设置]` 进入：

```
< 设置

字号
[-]  16  [+]

行距
[-]  1.2  [+]

[保存]  [预览]

[进入调试]

<                         >
```

### 10.2 状态模型

```
settingsCurrent  ← 内存中，调整时改变
settingsSaved    ← 持久化，保存时更新

进入设置 → settingsCurrent = settingsSaved
[-] [+] → settingsCurrent 改变
[预览] → 用 settingsCurrent 排版内置示例文本，原地显示
[保存] → settingsSaved = settingsCurrent，写入文件
返回不保存 → settingsCurrent = settingsSaved
```

### 10.3 预览

预览用内置示例文本，不打开其他书。点 `[预览]` 后，设置书正文区临时替换为编译期固定的示例文本，用新设置排版。再点 `[预览]` 或返回，恢复设置书正常内容。

示例文本包含中英文、标点、标题、空行，足以展示字号和行距效果。

### 10.4 阅读界面不碰设置

阅读界面只有 `<` 和书名、进度、正文、翻页行。没有设置按钮，没有菜单。

## 12. 跨平台架构

### 12.1 分层

```
应用层（平台无关）
  二进制解析 / 排版 / 翻页 / 进度 / 书树
平台抽象层（PAL）
  窗口 / 输入 / 文件 / 持久化
平台实现层
  Android (NDK) │ iOS (SDK)
```

### 12.2 PAL 接口

| 接口 | 功能 |
|---|---|
| `pal_window_create(w, h)` | 创建窗口 |
| `pal_poll_event(&event)` | 轮询输入 |
| `pal_file_open(path)` | 二进制打开 |
| `pal_file_mmap(handle)` | 内存映射 |
| `pal_store_write(key, data, len)` | 持久化写入 |
| `pal_store_read(key, buf, len)` | 持久化读取 |

### 12.3 渲染后端

Android：EGL + OpenGL ES 2.0/3.0
iOS：EAGL + OpenGL ES 2.0/3.0

所有 UI 由自建渲染引擎绘制，像素级一致。

## 13. 字体

文泉驿等宽正黑（WenQuanYi Zen Hei Mono）：

- 汉字宽度 = 西文宽度 × 2
- 字符宽度仅两种值，排版计算退化为计数
- 覆盖 GBK 全集

许可证：GPL v2。项目以 GPL 兼容许可证发布可静态嵌入；否则运行时从独立文件加载，About 页面注明。

加载方式：运行时加载，避免安装包膨胀。

## 15. 边界情况

| 情况 | 处理 |
|---|---|
| 空文件 | 行数 0，空白页，两个翻页键均不可用 |
| 仅一个 `\n` | 行数 1，空行，两个翻页键均不可用 |
| 末尾无 `\n` | 最后一行有效 |
| 连续 `---` | 第一个终止当前页，后续空页忽略 |
| 500 万连续 `\n` | 逐行渲染，不压缩 |
| 索引损坏 | 删除重建 |
| 源文件修改 | 哈希不匹配，索引失效 |
| 进度损坏 | 从头开始 |
| `\r\n` | 行尾 `\r` 视为内容 |
| 混合编码 | 不转换，按字节处理 |
| 翻页行空间不足 | 只显示 `<` `>` 符号，点击热区不变 |
| 第一页 | `<` 不可用（深灰），`>` 可用 |
| 最后一页 | `<` 可用，`>` 不可用（深灰） |

## 16. 正确性论证

### 16.1 翻页不重不漏

下一页从 `(lastSourceLine, lastByteOffset)` 或 `(lastSourceLine + 1, start)` 起始，保证前一页已渲染字节不重复、无遗漏。

### 16.2 进度一致性

sourceLine 是文件物理行号，与排版参数无关。同一进度在不同设备上定位到相同源文件行，行内偏移差异可接受。

### 16.3 内存有界

常驻数据仅有一级索引（O(L/K)）、当前页显示行（O(V)）、PageState（O(1)）。mmap 物理页由内核淘汰。翻页时旧页释放，新页生成，峰值 O(V)。

### 16.4 翻页行不侵占正文

翻页行是独立的显示行，不参与正文排版。正文区的视口容量 = 总显示行容量 − 顶栏 1 行 − 翻页行 1 行。正文排版只使用正文区的容量，翻页行不影响排版结果。

### 16.5 阅读界面与其他界面的翻页隔离

阅读界面正文区无组件，左右 1/2 点击翻页不会与组件冲突。其他界面正文区含组件，点击正文区仅触发组件，翻页只通过翻页行，保证组件交互的确定性。

### 16.6 翻页键状态与页面状态一致

canPrev 由 firstSourceLine == 1 判定，canNext 由 terminateReason == EOF 判定。每次翻页后重新计算，保证翻页键状态与当前页状态严格对应，不会出现"可用但点了没反应"或"不可用但点了有效"的情况。

## 17. 总结

| 决策 | 内容 |
|---|---|
| 格式 | 纯 TXT + 极简语法（标题、换页符） |
| 界面模型 | 一切皆书，书树导航 |
| 顶栏 | 始终可见，不可隐藏，固定一行 |
| 翻页行 | 真实一行，固定底部，不浮动 |
| 翻页键状态 | 可用（暗灰）/ 不可用（深灰），点击行为与状态一致 |
| 阅读翻页 | 正文左右 1/2 + 底栏 |
| 其他界面翻页 | 仅底栏，正文点击只触发组件 |
| 组件 | `[xxx]` 按钮、`(>)` 单选、`(-)` 多选 |
| 视觉 | 终端风格，黑底白字，8 色 |
| 进度 | 翻页即保存，只记行号 |
| 设置 | 书库的 `[设置]`，字号+行距，内置示例预览 |
| 存储 | 换行分隔二进制，定长记录 |
| 索引 | 自适应一级索引，上限 24KB |
| 触摸 | 只有单击 |
| 平台 | Android 4.4+ / iOS 12+ |
| 内存 | 常驻 < 35KB，峰值 < 2KB |

系统在理论上保证：内存有界、翻页不重不漏、进度跨设备一致、渲染结果确定性、存储文件可调试、翻页行不侵占正文、阅读与其他界面翻页行为隔离、翻页键状态与页面状态严格一致。所有算法均具备明确的复杂度上界与正确性论证。
