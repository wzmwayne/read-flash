## 1. 术语与行模型（新增 §1.3）

**源行（source line）**：由文件物理 `\n` 划分的行，行号从 1 开始（I1 不变）。

**文本行（text line）**：一个源行在排版中对应的内容单元。`---`、标题行都是文本行的一种。

**渲染行（render row）**：屏幕上一个**基础行高**的绘制单元。所有渲染行等高（这就是 §16.4"显示行"的准确含义）。

**网格（grid）**：启动与尺寸变化时按字号/行距/边距构建的整数像素网格（见 §4）。正文区被划分为 `C` 个半角列 × `V` 个渲染行。

**不变量 R1（新增，续 I1–I9）**：在**阅读书**中，每个源行至少产生 1 个渲染行。依据：`---` 依 A5 填空白至页底、标题占 1–2 行、空行也占 1 行。R1 是 §8「上一页回溯」正确性的前提。

> 由此，"文本行 → 渲染行"的映射方式（B2，**v3.4.1 定稿**）：
> 1. **换行渲染**：超宽文本行折为多个渲染行，渲染行数 > 文本行数。**阅读书强制使用本模式，永不滚动**。
> 2. **截断 + 点击滚动**（仅**生成式书**可用，书级声明）：每个文本行固定占 1 个渲染行，超出部分截断，**行尾固定显示 1 个半角列宽度的省略号 `…`**；该行是可交互元件（需分配交互 ID，§3.2），**点击该行开始滚动**——每 500ms 向左移动 1 个半角列、无动画直接跳，滚到行尾停留 1 个周期后回到行首循环；**再次点击停止并复位**（回行首、恢复 `…`）；翻页或离开该书时同样停止并复位。该模式不改动进度锚点，仅影响显示。
>    阅读书禁用本模式的理由：滚动会与"正文左/右 1/2 翻页"的热区冲突，且同一屏内容随计时变化会破坏 §16 的渲染确定性。

## 2. 界面结构（替换 §2.2；修订 §16.4）

```
┌─────────────────────────────────────┐
│ <  界面名                            │  顶栏：1 个基础行高，全宽，永不隐藏
├─────────────────────────────────────┤
│                                     │
│              正文区                  │  C 列 × V 个渲染行
│                                     │
├─────────────────────────────────────┤
│ [按钮] [按钮]            （可选行）   │  底栏上行：按钮/文字行
│ <                              >    │  底栏下行：固定翻页行
└─────────────────────────────────────┘
```

- **顶栏**（1 个基础行高）：最左为 `<` 返回，中间为**界面名**。阅读书的界面名 = `阅读器-书名`；无其它元素（B2、E6）。
- **正文区**：`C` 列 × `V` 个渲染行，可上下留边距（见 §4）。
- **底栏**（2 个基础行高）：
  - 上行 = **可选按钮/文字行**：没有内容时**保留为空行**，不自动压缩（A9）。
  - 下行 = **固定翻页行**：`<` 左对齐、`>` 右对齐，中间不响应（2.4 不变）。
- **容量公式（替换 §16.4）**：

  ```
  V = floor((屏高 − 3 × Rh − m_top − m_bottom) / Rh)      // Rh = 基础行高；3 = 顶栏 1 + 底栏 2
  C = floor((屏宽 − m_left − m_right) / Wc)               // Wc = 半角列宽
  ```
  排版只使用 `C × V`，顶栏与底栏不参与正文排版（16.4 的结论保留，行数改为 3）。

- **翻页键可用性**（替换 §2.3/§7.4 的判定，见 §8）。
- **翻页热区**：左右各 `max(屏宽 × 20%, 44dp)`，向下取整到半角列；中间区域不响应；不可用时热区仍存在但点击被忽略（I9 不变）。

## 3. 交互 ID 与书模型（新增 §2.7、§2.8）

### 3.1 书的两类来源

| 类别 | 内容来源 | 例子 | 是否解析交互组件 | 是否保存进度 |
|---|---|---|---|---|
| **阅读书**（file-backed） | `<app_data>/book/<ID>/book` | 用户导入的 TXT | 否（仅换页符、标题） | 是 |
| **生成式书**（generated） | 代码生成字节流 | 书库、设置、调试、提示框 | 是 | 否（B7） |

两类书**共用**同一套网格、排版、渲染、触摸管线（I5），差异只在"内容从哪来"与"解析哪些语法"（A1、A9）。

### 3.2 交互 ID（A9）

- 格式：`[a-z0-9_]+`，即小写字母、数字、下划线。
- 同一界面内**全局唯一**；由书（生成器）为每个可交互元件分配。
- **保留 ID**（不可复用、不可改）：`nav_back`（顶栏 `<`）、`page_prev`（翻页行 `<`）、`page_next`（翻页行 `>`）。
- 触摸/按键分派按 ID 进行：`命中元件 → ID → 该书注册的动作`。视觉与热区由渲染网格推导（§5）。

### 3.3 提示框书（A15）

- 一类特殊的生成式书：**全屏绘制**的模态框，等价于系统弹窗。
- 底栏按钮行放 `[确定] [取消]` 等按钮；顶栏 `<` 语义 = **取消**。
- 用途：删除确认、非 UTF-8 提示、建立索引进度提示。

### 3.4 书库（替换 §2.6 的书库部分，B6）

- 书名与目录（TOC）来自 `.config`，不读正文。
- 选书 = **单选组件**（`~~~` 组 + `(>)`），选中只改变选中态，**不打开**；`[打开]` 作用于当前选中项。
- 行内容 = `书名 + 进度百分比`；百分比为段色（B3）。
- 百分比 = `L == 0 ? 0 : floor(sourceLine × 100 / L)`（自决）。
- 底部按钮行：`[打开] [删除] [导入]`；`[删除]` 用危险色并走提示框书确认。

### 3.5 内置书：应用使用教程（新增）

- 书库**单选组只列书**：内置 **《应用使用教程》** + 导入的书；**《设置》与《调试》是主界面底栏按钮**（`[打开][删除][导入][设置][调试]`），不是单选项。内置书不可删除、不参与导入导出、不写进度。
- 《应用使用教程》内容（生成式，按 V 分页）：
  1. 欢迎与定位：终端风格 · 极低端设备 · 纯文本阅读器；
  2. 书树导航：顶栏 `<` 返回；翻页行 `<` `>`；**阅读界面**正文左右 1/2 翻页；
  3. 组件说明：`[按钮]`、`{禁用}`、`(>)单选`、`(-)多选`、`~~~` 组、`---` 换页符、`#`/`##`/`###` 标题；
  4. 设置：字号 / 行距 / 行高 / 上下左右边距、`[预览]`/`[保存]`，首次启动自动进入设置；
  5. 书库与导入：`[打开] [删除] [导入]`，`[删除]` 走**提示框书**二次确认；
  6. 进度与调试：翻页即保存、按 `(行号, 行内偏移)` 恢复、调试页可 `[重建索引]`/`[重置进度]`。
- 教程书本身即"一切皆书"的示例：与其他书共用同一套网格、排版、渲染、触摸管线（I5）；书内按钮只更新底栏提示行，**不产生副作用**。
- 阅读书**不解析**交互组件（§5.5），因此教程中展示的组件语法在阅读书里只会按原文显示。

## 4. 网格与视口（新增 §6.0；实现 A11、A12）

### 4.1 设置项（定稿取值域）

| 项 | 单位 | 默认 | 范围 | 步长 |
|---|---|---|---|---|
| 字号 F | dp | 16 | 12 – 48 | 1 |
| 行高 H | dp：**行容器的高度**（相邻行容器紧贴堆叠，容器高 = 排版推进量）；0 = 自动（字号 × 1.2） | 0 | 0 – 96 | 2 |
| 边距（上/下/左/右） | dp | 8 | 0 – 64 | 2 |

- 全部为**整数**，不使用浮点（P4）；显示 `R / 1000` 保留 1 位小数。
- 行距下限 1000‰ 保证 `#`（2× 字号）在 2 个渲染行内不重叠。
- 首次启动时**自动进入设置书**（A12），用户可先调字号/边距再进书库。

### 4.2 网格构建（整数运算）

```
D   = density                            // 整数千分比，1000 = 1.0×（PAL 以 ‰ 返回，见 §10.1）
Fp  = (F × D + 500) / 1000               // 字号像素，四舍五入，下限 1
m_* = (m_dp × D + 500) / 1000            // 四向边距像素
Wc  = (Fp + 1) / 2                       // 半角列宽 = ceil(Fp / 2)；全角 = 2 × Wc
Rh  = (Fp × R + 999) / 1000              // 基础行高 = ceil(Fp × R / 1000)
C   = (屏宽 − m_left − m_right) / Wc     // 整数除法即 floor
V   = (屏高 − 3 × Rh − m_top − m_bottom) / Rh
```

> 全程整数除法（`/` 为向下取整的整数除），不出现任何浮点（P4、A11）。

**自动边距（A12：只能多于设置值）**：

```
m_right  += (屏宽 − m_left − m_right) − C × Wc              // 水平余数全部给右边距
m_bottom += (屏高 − m_top − m_bottom) − (V + 3) × Rh        // 纵向余数全部给下边距
```

**区域矩形**：

- 顶栏：`(m_left, m_top, C × Wc, Rh)`
- 正文区：`(m_left, m_top + Rh, C × Wc, V × Rh)`
- 底栏上行：`(m_left, m_top + (1 + V) × Rh, C × Wc, Rh)`；下行（翻页行）：`(m_left, m_top + (2 + V) × Rh, C × Wc, Rh)`
- **文字在行容器内的对齐**：字形高 ≤ 容器高 → 容器内垂直居中；字形高 > 容器高 → **顶部对齐容器顶，超出部分照常渲染（不裁剪）**，允许压到相邻行

屏幕尺寸/DPI/安全区变化时重算以上全部并实时重排（D3）。长整数运算由自建模块提供（A11）。

## 5. 排版（替换 §6.1–§6.4）

### 5.1 解码与宽度分类（替换 §6.1、§6.2；实现 A13、D7、D8）

- 自建 UTF-8 解码器；允许 BOM（跳过不显示）；非法序列 → 替换字形，按**半角**占位。
- **列宽只有两档**：全角 = 2 列，半角 = 1 列。不存在 0 宽字符（v3.3 的"其他 0"作废）。
- 全角判定按**码点区间**（不是首字节 `0xE4–0xE9`）：

  ```
  全角：U+1100–U+115F, U+2E80–U+A4CF, U+AC00–U+D7A3, U+F900–U+FAFF,
        U+FE10–U+FE19, U+FE30–U+FE6F, U+FF00–U+FF60, U+FFE0–U+FFE6,
        U+1F300–U+1F64F, U+1F900–U+1F9FF, U+20000–U+3FFFD
  半角：其余全部（含 ASCII、拉丁扩展、`\t`、替换字形）
  ```

- **排版不依赖字体的 advance**：字形按所在列矩形缩放/居中绘制并裁剪（D8）。宽度累加只有加法与移位（全角 +2、半角 +1），P5 成立。

### 5.2 断行（替换 §6.2 的断行部分）

- 逐字符累加列宽，`acc + w > C` 时在该字符**之前**断行；`acc + w == C` 不断行。
- 不做避头尾（kinsoku）、不做英文按词断行（v1 明确如此，需写入文档）。
- **截断模式**（仅生成式书，§1.3）不执行本节折行：直接取前 `C − 1` 个半角列的内容，第 `C` 个半角列固定绘制 `…`；内容未超宽时不显示 `…`，该行也不成为滚动元件。
- 单个字符的宽度不会超过 `C`（`C ≥ 1` 由网格保证）。

### 5.3 标题（替换 §6.4；B11）

| 语法 | 占用渲染行数 | 字号 | 渲染 |
|---|---|---|---|
| `### ` | 1 | 1.0 × Fp | 加粗 |
| `## ` | 2 | 1.5 × Fp | 加粗、**贴顶**，下方留 0.5 行空白 |
| `# ` | 2 | 2.0 × Fp | 加粗、贴顶 |

> 语义就是"占 N 个渲染行 + 用 scale × Fp 的字形"；下方留白（`##` 的 0.5 行）属于行内空白，不产生额外的渲染行。

- 列宽随字号等比放大：该行可容纳列数 = `floor(C / scale)`，`scale ∈ {1, 1.5, 2}`。
- 4 个及以上 `#`、`#` 后无空格、行首空白后跟 `#` → 按普通文本行。
- 标题颜色为默认色表中的标题色（§6）。

### 5.4 换页符（替换 §6.3；A5）

- 判定：行内容**精确等于** 3 字节 `---`（无前导/尾随空白，不接受 `\r` 变体）。仅在**阅读书**生效。
- 行为：当前页从 `---` 处起，**剩余全部渲染行填空白**直到页底；下一页从 `---` 的下一源行开始。
- `---` 行本身不渲染字符，但仍占一个源行号并参与进度。
- 不提供转义语法；要显示字面 `---` 请写 `----` 或在前后加空格。

### 5.5 组件语法作用域（新增 §4.6）

| 语法 | 阅读书 | 生成式书 | 备注 |
|---|---|---|---|
| `#` `##` `###` 标题 | ✅ | ✅ | §5.3 |
| `---` 换页符 | ✅ | ❌ | A5：其他界面不解析 |
| `[xxx]` / `{xxx}` 按钮 | ❌ 按原文渲染 | ✅ | 阅读书不解析交互组件 |
| `~~~ /~~~` `(>)` `(-)`/`(+)` | ❌ 按原文渲染 | ✅ | 同上 |
| 行首 `<` 返回 | ❌ 按原文渲染 | ✅ | |

- 单选组：合法的 `~~~ … /~~~` 组标记**本身不渲染**；**未闭合或非法**时按下述边界整段按普通文本行渲染（B10）：
  - 边界 = 从该 `~~~` 行起（**含 `~~~` 本身**）直到**下一个 `---` 行或文件末尾**之间的所有行；
  - 这一段内 `~~~`、`(>)`、`(-)` 等标记一律按字面文本渲染，不产生组件、不参与单选状态。
- 组可跨页、跨 `---`，**不可嵌套**；组内无选中项时不处理；若出现多个选中项，操作时先清除全部再选中目标（B10）。

## 6. 颜色与焦点（替换 §3.1–§3.3；B4、B5）

- **取消固定调色板**：颜色不再是应用的全局约束，而是**段（span）属性**（B3）；书源/生成器可逐段指定（B5 的"手动更改按钮颜色"）。
- 默认色表（仅作默认值，可覆盖）：正文 `#E0E0E0`、标题 `#00FFFF`、按钮 `#00FF00`、禁用/不可用 `#333333`、危险 `#FF4444`、次要信息/可用翻页键 `#666666`、背景 `#000000`。
- 阅读书使用默认色表；保留"纯黑背景"以利 OLED 省电（§3.1 的动机不变）。
- **交互焦点配色**：元件被按下/获得焦点时，前景 = 背景色（默认 `#000000`），背景 = 原前景色（反色）；抬起恢复原配色并触发该 ID 的动作（B4）。该机制为将来纯键盘操作预留。
- 渲染：字形位图缓存为 alpha 通道，绘制时以颜色乘 alpha（§3.3 不变）；帧缓冲为 RGB565，按网格行脏区重绘（D4）。

## 7. 触摸（替换 §11.2、§11.4）

- **单击** = DOWN 后 300ms 内 UP，且 `max(|dx|, |dy|) < 10 dp`（逻辑像素；B14）。
- **取消**（恢复视觉、不触发）：超时、位移超限、收到 CANCEL、触点离开窗口、出现第 2 个触点、应用退到后台。
- **多指**：仅第一个 DOWN 有效，出现第二指即取消。
- **按下反馈**：DOWN 立即切焦点配色，UP 恢复并触发（§6）。
- **热区**：由网格推导，组件矩形向上下各扩 1 个渲染行、左右各扩 2 个半角列；重叠时按"触点与组件中心距离最近"归属，等距取先绘制者；顶栏/底栏热区优先级最高（B13）。
- **截断行**（仅生成式书，§1.3）：整行矩形即其热区，点击开始/停止滚动。阅读书不产生此类热区，正文区仍严格按左/右 1/2 翻页。
- 全应用**无手势滚动、无滑动、无长按、无双击**（B16）；唯一的"滚动"是生成式书截断行的点击触发自动滚动（§1.3），它不是手势。阅读书正文区左 1/2 / 右 1/2 翻页（I8 不变），其他界面正文点击只触发组件。

## 8. 页面状态与进度（替换 §7.1、§7.4、§8.1–§8.4）

### 8.1 PageState v3.4

```
PageState {
    firstSourceLine:  uint64
    firstByteOffset:  uint64   // 页首在源文件中的绝对字节偏移（新增）
    lastSourceLine:   uint64
    lastByteOffset:   uint64   // 下一页续排起点（新增，A3）
    displayRowCount:  uint16   // 恒 = V（不足部分为空白渲染行）
    terminateReason:  uint8    // 位标志：0x01 FILLED | 0x02 FORCED | 0x04 EOF（可组合）
}
```

- `canPrev = firstByteOffset > 0`（**替换** `firstSourceLine == 1`，修正 A2：单行跨页时 `<` 不再误判为不可用）。
- `canNext = (terminateReason & EOF) == 0`。
- 终止原因组合规则（A5）：
  - 排满且文件结束 → `FILLED | EOF`（`canNext = false`，不再出现"可用但点了得到空页"）。
  - 遇 `---` 且后面还有内容 → `FORCED`。
  - 遇 `---` 且后面无内容 → `FORCED | EOF`（`canNext = false`，**尾随 `---` 不产生空页**）。
  - 空文件 → `EOF`（两个键都不可用）。
- 判定 EOF 需向前预读 1 个字节/1 个源行（实现要求，写入 §7.2）。

### 8.2 进度（替换 §8.1；A2、B19）

```
ReadingProgress {
    sourceLine: uint64    // 页首所在源行
    lineOffset: uint64    // 页首在该行内的字节偏移
    totalLines: uint64    // 写入时的 L，用于防御性校验
    timestamp:  uint64    // Unix 秒
}
```

- 恢复 = 以 `(sourceLine, lineOffset)` 为**页首锚点**实时排版（B19）。
- 跨页续行时锚点仍记该源行 + 行内偏移，**不再出现"偏移几行"的近似**（A2/A3 修正 v3.3 §8.3）。
- **`lineOffset` 必须对齐到 UTF-8 字符边界**：保存时向下取整到最近的字符起始字节；载入时若偏移落在字符中间（例如被外部篡改），同样向下取整并计一次异常。
  - 取整方向选"向下"的理由：该字符会在恢复后的页面里重新完整显示一次（属 I3 允许的行内重复）；"向上"取整会**跳过**一个字符，属于内容丢失。
- 保存时机不变：翻页即保存（§8.2 保留），落盘为原子替换且不 fsync（C8/C9）。

### 8.3 上一页回溯（替换 §7.3；A16）

```
prevPage():
    B = max(1, cur.firstSourceLine − (V + 2))
    从 B 起实时排版，累积渲染行，取"结束于 cur.firstByteOffset 之前的最后 V 行"
```

**实现定稿（v3.4.2，已由 core 自检逐页验证）**

```
prevPage(cur):
    B = cur.anchor_line − (V + 2)（下限 1）
    从 B 起迭代渲染行；遇到 `---` 则清空窗口，并把清空前的行留作快照
    窗口 = 抵达 cur 之前的最后 V 个渲染行（窗口为空时改用快照）
    丢弃窗口首部直到落在块首（标题块不拆分）
    上一页首锚点 = 窗口首行 start_off；末锚点 = cur.anchor_off
```

- **保证**：反向连续翻页严格铺满 `[0, 锚点)` —— 不重不漏；每页首锚点必为块首；锚点必对齐 UTF-8 字符边界。
- **与正向链的差异**：当标题块导致正向"提前换页"时，反向页可能比正向页多含一个块（即 I3 允许的"偏移几行"），但既不丢内容也不重叠。
- 前提 R1（§1.3）保证 V+2 行的窗口至少覆盖 V 个渲染行；若未来阅读书引入不产生渲染行的语法，必须改为倍增回溯。

## 9. 存储（替换 §1.1 P3、§5.2、§9）

### 9.1 通用规则（替换 §9.4）

- 文件 = 若干行，每行以 `\n`(0x0A) 结尾，**最后一行也必须有 `\n`**；文件是 ASCII/UTF-8 混合行文本。
- 数值字段 = **大写十六进制、定宽**（uint64 → 16 位，uint32 → 8 位，uint16 → 4 位），前导零补齐；禁止 `+`/`-`/空格。
- 文本字段 = UTF-8 原文（不含 `0x0A`、`0x00`）。
- 行 1 = 魔数（6 个 ASCII 字符）+ 3 位十进制版本，如 `RFIDX001`。
- 最后一行 = **CRC-32/ISO-HDLC**（多项式 `0xEDB88320`，初值 `0xFFFFFFFF`，反射，末尾异或 `0xFFFFFFFF`，即 zlib `crc32`），8 位大写十六进制；覆盖范围 = 首字节至校验行之前（含各行尾 `\n`）。
- 所有写入 = `tmp + rename` 原子替换（C8/D10）；校验失败 → 改名 `*.bad` 后重建/重置。

### 9.2 目录布局（A10）

```
<app_data>/config               全局配置   RFSET001
<app_data>/book/<ID>/book       正文（导入时复制，此后只读）
<app_data>/book/<ID>/.config    书信息     RFBOOK001（书名、目录、S、L）
<app_data>/book/<ID>/.rfidx     索引       RFIDX001
<app_data>/book/<ID>/.progress  进度       RFPROG001
<app_data>/trash/<ID>           删除中转
```

`<ID>` = 8 位大写十六进制：前 6 位 = `CRC32(book)` 的高 3 字节；后 2 位 = 冲突序号（初始 `00`，冲突递增到 `FF`；用尽后改用 CRC32 低 3 字节重算）。

### 9.3 字段表

**全局配置 `config`（RFSET001）**

```
行1  RFSET001
行2  字号 F     4 位 hex (uint16, dp)
行3  行距 R     4 位 hex (uint16, ‰)
行4  上边距     4 位 hex
行5  下边距     4 位 hex
行6  左边距     4 位 hex
行7  右边距     4 位 hex
行8  CRC32      8 位 hex
```

**书信息 `.config`（RFBOOK001）**

```
行1  RFBOOK001
行2  书名            UTF-8 文本（导入时的无后缀文件名，≤ 255 字节）
行3  正文字节数 S     16 位 hex
行4  正文全文 CRC32   8 位 hex
行5  行数 L          16 位 hex
行6  目录条目数 T     8 位 hex
行7 … 行6+T  目录条目： "行号16位hex 标题UTF-8"（标题 = 正文中的 `#` 行）
行7+T  CRC32         8 位 hex
```

> 书库只需读 `.config` + `.progress` 即可显示书名、目录与百分比，不必加载索引；`L = 0` 时显示 `0%`。

**进度 `.progress`（RFPROG001）**

```
行1  RFPROG001
行2  sourceLine   16 位 hex（0 = 无位置，用于空文件）
行3  lineOffset   16 位 hex
行4  totalLines   16 位 hex
行5  timestamp    16 位 hex（Unix 秒）
行6  CRC32        8 位 hex
```

**索引 `.rfidx`（RFIDX001）**

```
行1  RFIDX001
行2  L            16 位 hex
行3  S            16 位 hex
行4  H1           8 位 hex   // CRC32(首 min(S,4096) 字节)
行5  H2           8 位 hex   // CRC32(尾 min(S,4096) 字节)
行6  K            8 位 hex   // uint32
行7  N            8 位 hex   // 条目数
行8 … 行7+N   index1[0..N−1]，每行一个 16 位 hex 字节偏移
行8+N  CRC32      8 位 hex
```

### 9.4 索引参数与自校验（替换 §5.2 的 K 公式与 §15 的"索引损坏"行）

```
K = (L == 0) ? 256 : clamp(2^ceil(log2(L / 4096)), 256, 16777216)   // 2 的幂
N = (L == 0) ? 0   : ceil(L / K)
index1[j] = start(j × K + 1)          // j ∈ [0, N)
```

- 索引字节数 = `N × 17 + 头部`；未触顶时 `N ∈ (2048, 4096]` ⇒ **约 35–70 KB**。v3.3 的"上限约 24KB"**作废**；K 触顶后随 L 增长（A6：不设硬限制）。
- 加载时逐项校验，任一失败即重建：
  1. 魔数与版本；2. CRC32；3. `K` 为 2 的幂且 `256 ≤ K ≤ 2^24`；4. `N == (L>0 ? ceil(L/K) : 0)`；
  5. `index1[0] == 0`；6. `index1` 严格递增；7. `index1[N−1] < S`；8. `S/H1/H2` 与正文一致。
- **校验时机**：上述 8 项只在**打开某一本书**时执行，**不在书库列表时**执行。书库按 §9.3 只读 `.config` + `.progress`，因此进入书库不会产生"N 本书 × 8KB"的正文读取。
- 打开时重算 `S/H1/H2`（≤ 8KB 读取，不使用 mtime），命中即用索引（C7）。
- `K` 的上限 `2^24` 需 `L > 2^36 ≈ 687 亿行`才会触及，**v1 实际不会触发**，保留仅为防御性设计（触及瞬间 `N` 恰为 4096）。

### 9.5 空文件（C12）

`S = 0`、`L = 0`：索引只有头部（`K = 256`，`N = 0`）；进度写 `(0, 0, 0, ts)`；打开显示空白页，两个翻页键都不可用。

## 10. PAL 与渲染（替换 §12.2；补充 §12.1）

### 10.1 接口（D1）

| 分类 | 接口 |
|---|---|
| 窗口 | `pal_window_create(w,h)`、`pal_window_size(&w,&h)`、`pal_poll_event(&e)` |
| 文件 | `pal_file_open/close/size/read/mmap/munmap`、`pal_file_write_atomic(path,buf,len)`、`pal_file_delete(path)`、`pal_path_exists(path)` |
| 目录 | `pal_dir_create(path)`、`pal_dir_list(path,cb)`、`pal_dir_delete_recursive(path)` |
| 路径 | `pal_app_data_dir(buf,len)` |
| 时间 | `pal_ticks_ms()`（单调）、`pal_now_unix()` |
| 显示 | `pal_display_metrics(&w,&h,&density,&safe_insets)`（`density` 为整数千分比，1000 = 1.0×） |
| 日志 | `pal_log(level,msg)` |

- **单线程模型**（D2）：主循环 `poll_event → 状态更新 → 脏区重绘 → 上屏`；PAL 不提供线程接口。
- 允许的阻塞：导入/建索引 ≤ 300ms/5MB，超出则分片执行并在提示框书显示"正在建立索引…"；禁止在渲染路径内做文件 I/O。
- 分层图补入平台外壳（Android Activity/JNI、iOS App 生命周期与沙箱路径）（§12.1）。

### 10.2 渲染（D4、D5）

- CPU 软件渲染到 **RGB565 帧缓冲**，按**网格行脏区**重绘（记录本帧需重绘的行区间，最多整屏）；上屏用 GLES `glTexSubImage2D` 只上传脏区。
- **上传前必须设 `glPixelStorei(GL_UNPACK_ALIGNMENT, 2)`**：RGB565 每像素 2 字节，而 GL 默认行对齐为 4；脏区宽度为奇数时会按 4 字节补齐，导致错行/错色。
- 静止时 0 帧（不空转重绘）；翻页时单帧 ≤ 10ms；**截断行滚动期间**按 500ms 周期重绘该行（每周期仅 1 个渲染行，是"0 帧"的唯一例外，且只出现在生成式书）。
- 渲染后端抽象为 `render_backend`（清屏 / 纹理上传 / 绘制三角形），iOS 后续可换 Metal；文档记录 GLES 在 iOS 12+ 已弃用（D5）。
- 帧缓冲计入应用峰值内存、不计入调试页的"常驻"（E2）。

## 11. 性能与验收口径（替换 §14）

| 场景 | 输入 | 口径 |
|---|---|---|
| 定位任意行 | 行平均长度 ≤ 128B | 平均 ≤ 0.1ms；**最坏 = O((K−1) × 区间最大行长)，不作保证** |
| 导入 | 5MB | ≤ 300ms（含扫描、建索引、写盘） |
| 二次打开 | 任意 | ≤ 10ms（读索引 + ≤8KB 校验） |
| 下一页 | V ≤ 40 行 | ≤ 10ms（含重排与渲染） |
| 上一页 | V ≤ 40 行 | ≤ 20ms |
| 内存 | — | **A8 用户决定暂不设硬预算**；调试页仅显示"自管分配字节数" |

验收测试矩阵（D11）：

1. **排版确定性**：同参数同输入 → 帧缓冲逐字节一致（软件渲染使跨设备可比）+ 黄金图像回归。
2. **翻页不重不漏**：逐页渲染的字节区间拼接 == 从页首锚点到文件尾的完整字节流；随机翻页顺序做不动点测试。
3. **边界语料**：空文件、单 `\n`、无 `\n` 的 5MB 单行、500 万连续 `\n`、超长行、`---` 在首/中/尾、`~~~` 未闭合、非法 UTF-8。
4. **存储**：CRC 篡改、文件截断、版本不匹配、写入中途 `kill -9`。
5. **恢复**：不同字号/边距/屏幕尺寸下，锚点必须落在同一源字节。

## 12. §15 边界情况增补

| 情况 | 处理 |
|---|---|
| 文件结尾是 `---` | 末页 `FORCED｜EOF`，`canNext = false`，**不产生空尾页** |
| 一页恰好排满且文件结束 | `FILLED｜EOF`，`canNext = false` |
| 单个源行跨多页 | 锚点用 `(sourceLine, lineOffset)`；`canPrev` 看 `firstByteOffset`，不再误判 |
| 阅读书里出现 `[x]`、`~~~`、`(+)`、行首 `<` | 按**原文**渲染，不产生组件 |
| 生成式书里出现 `---` | 按普通文本行渲染 |
| `~~~` 未闭合/非法 | 从该 `~~~`（含）到下一个 `---` 或文件末尾整段按普通文本行渲染（§5.5） |
| 单选组内多个选中 | 操作时先清除全部，再选中目标 |
| 非 UTF-8 文件 | 非法序列渲染替换字形；导入时非法比例 > 1% 用提示框书告知 |
| 屏幕尺寸/旋转变化 | 重建网格、重算边距（只增）、按锚点重排、写回进度 |
| ID 冲突 | 生成器保证唯一；保留 ID 不得占用 |
| 空文件 | 索引 `N = 0`，进度 `(0,0)`，书库显示 `0%`，两键均不可用 |

## 16. 落地前的最小验证（评审建议，实现阶段执行）

用一份 5MB 中文 TXT，在 Android 上只实现四件事——**网格构建 + UTF-8 解码 + 断行 + 单页渲染**——验证：

1. `C` 与 `V` 在多种屏幕尺寸/DPI 下算得正确（含自动边距"只增不减"）。
2. 断行结果确定：同参数同输入 → 渲染结果逐字节一致（字号变化后重排仍需确定）。
3. `(sourceLine, lineOffset)` 锚点恢复后，页首字符与保存时一致（含跨页续行与 UTF-8 边界对齐）。

三件事通过后，索引 / CRC / 书库 / PAL 均属工程实现，不再是理论风险。
