# EZBK（EasyBook）富文本格式规范 v1.1

> 格式名：**EZBK**（全称 EasyBook Rich Text / 简单电子书格式）｜扩展名 `.ezbk`｜MIME `text/x-ezbk; charset=utf-8`
> 适用：Read-Flash、ReaderPlus｜状态：草案

## 0. 一句话定义

EZBK 是**纯文本、行导向**的电子书格式：一行一个语义单元 ——
`#`/`##`/`###` 开头是三级标题，`@` 开头是**命令行**，`\\` 开头是转义行（不解析），其余是正文段落。

| 项 | 值 |
|---|---|
| 字符集 | UTF-8（无 BOM） |
| 换行 | 写出统一 `\n`；读入兼容 `\r\n` |
| 可选首行魔数 | `EZBK0001`（缺省视为 v1 文档） |
| 二进制资源 | **base64 内嵌**（见 §5），或外置相对路径 |

## 1. 设计目标

1. **纯文本**：不引入二进制容器，可 `grep`、可 diff、可由脚本直接生成；
2. **行导向**：解析只需「按行判断首字符」，无需正则/XML 库；
3. **命令单行化**：`@` 一律是**单行命令**，没有块结构 —— 解析器不需要状态机；
4. **前向兼容**：不认识的 `@` 命令**必须忽略**，不得报错；
5. **向后兼容**：删掉所有 `@` 行即「纯文本 + 标题」基线。

## 2. 行类型总表

| 行首 | 类型 | 是否解析 |
|---|---|---|
| `#` / `##` / `###` | 标题（1/2/3 级） | 是 |
| `@` | **命令行** | 是（未知命令忽略） |
| `\\`（双反斜杠） | **转义行** | 否：去掉两个 `\\` 后按字面显示 |
| 空行 | 段落分隔 | 忽略/折叠 |
| 其他 | 正文段落 | 按原文保留 |

判定顺序：**先转义、再标题、再命令、最后正文**。

## 3. 标题

1. 行首 `#` 数量即级别：`#` 章、`##` 节、`###` 小节；
2. `####` 及以上**按 3 级处理**（不做第 4 级）；
3. 标题行原始字节数必须 **< 120**，超长视为正文段落；
4. 空标题（仅 `#` 或 `# `）降级为正文段落；
5. 目录由标题行**推导**，无需单独维护。

## 4. 命令行（`@`）

### 4.1 语法

```
@<命令> <参数1> <参数2> ...
```

- **单行**：一条命令只占一行，没有块、没有结束标记；
- **参数按空格分隔**；参数本身含空格时用**双引号**包裹（`@image "res/my cover.jpg" 封面`）；
- 行首 `@` 后紧跟命令名（不含空格），命令名与参数之间至少一个空格；
- **未知命令**：忽略该行并计数告警，不中断解析。

### 4.2 标准命令

| 命令 | 参数 | 语义 |
|---|---|---|
| `@image` | `<src> [alt]` | 插入图片；`src` 可为相对路径或 `blob:<名>`（见 §5） |
| `@hr` | — | 分隔线 |
| `@meta` | `<key> <value>` | 文档元数据；应出现在首个标题之前，可多次 |
| `@toc` | — | 目录锚点（一般不需要） |
| `@blob` | `<名> <base64>` | 注册内嵌二进制资源（见 §5） |

示例：

```
EZBK0001
@meta title 夜航船
@meta author 张岱
@blob cover iVBORw0KGgoAAAANSUhEUg...
@image blob:cover 封面
# 序
天下学问，惟夜航船中最难对付。
## 一、天文
@hr
正文第一段。
```


## 4.3 `@meta` 键表

| 键 | 语义 | 必需 |
|---|---|---|
| `title` | 书名（缺省取首个标题） | 否 |
| `author` | 作者 | 否 |
| `language` | 语言标签（如 `zh`） | 否 |
| `identifier` | 稳定标识（用于去重/同步） | 否 |
| `date` | 出版或创建日期（ISO 8601 日期串） | 否 |
| `publisher` | 出版方 | 否 |
| `description` | 简介 | 否 |
| `cover` | 封面引用：`blob:<名>` 或相对路径 | 否 |
| `series` | 系列名 | 否 |
| `series-index` | 系列序号 | 否 |

未列出的键：**保留并忽略**（前向兼容），不得报错。

## 5.1 `@blob` 的渲染规则

`@blob` **只是资源池**，本身不渲染；渲染由**引用它的命令**决定：

| 引用点 | 支持的 MIME | 渲染行为 |
|---|---|---|
| `@image blob:<名>` | PNG / JPEG / WebP / GIF | 解码为图片显示；失败显示 alt 与占位框 |
| `@image <相对路径>` | 同上 | 从 `*.res/` 读取后同上 |
| 其它（音频/字体/zip 等） | — | **不渲染**：保留在资源池，仅 `blob:` 引用可被脚本或导出读取 |

限制与降级：

1. 单条 `@blob` 解码后 > 256 KB → 告警（不阻断），建议改外置；
2. MIME 由字节头嗅探，不信任扩展名；
3. 非图片 blob 在阅读界面**静默忽略**（必要时显示一行提示），不得崩溃；
4. 导出 EPUB 时：图片写入包内；非图片 blob 丢弃并记日志。

## 5. 二进制资源：base64 内嵌

1. **内嵌**：用 `@blob <名> <base64>` 注册，随后 `@image blob:<名>` 引用；
   - base64 **必须是单行**（不折行）；
   - 单条 `@blob` 建议 ≤ 256 KB（base64 后约 341 KB），超大资源应外置；
2. **外置**：`@image res/cover.jpg`，路径相对 `.ezbk` 文件；
3. **安全**：拒绝 `../`、绝对路径、`file:` 等 scheme，仅允许相对路径与 `blob:`。

## 6. 转义行

以**双反斜杠** `\\` 开头的行不参与解析：

```
\\# 这行不是标题，会原样显示为「# 这行不是标题...」
\\@image 这也不是命令
```

用途：正文里需要书写看起来像标题/命令的原文时使用。仅去掉**行首两个**反斜杠，其余原样。

## 7. 与 Read-Flash 存储的对应

| Read-Flash 文件 | 说明 |
|---|---|
| `book/<ID>/book` | **即 EZBK 文档本体**（UTF-8 行文本） |
| `book/<ID>/.config` | `RFBOOK001` + 书名 + 长度/CRC/行数/目录条数 + 目录项 + CRC32 |
| `book/<ID>/.rfidx` | `RFIDX001` + 索引块偏移 + CRC32 |
| `book/<ID>/.progress` | 阅读进度 |

落盘约定沿用 Read-Flash：ASCII 行文本 + CRC32 末行 + `写 .tmp → rename` 原子替换。

> **兼容提示**：Read-Flash 现有实现只把「行首 `#` 且 <120 字节」当目录项，
> 因此 `##`/`###` 会被计入但标题文本带前缀；`@` 行会按普通文本显示。
> 这些都是**可读的降级**，不影响文件正确性。

## 8. 格式互转

### 8.1 EZBK → TXT
丢弃 `@` 行、内联标记与 `blob:` 资源；标题转为纯文本；转义行去掉行首两个 `\\`。

### 8.2 EZBK → EPUB
| EZBK | EPUB |
|---|---|
| `#`/`##`/`###` | 分文件或 `<h1>/<h2>/<h3>` + nav |
| `@image` | `<img>`（`blob:` 解码后写入包内） |
| `@hr` | `<hr>` |
| 内联标记 | `<strong>/<em>/<code>/<s>` |

### 8.3 EPUB/TXT → EZBK
- 标题层级 ≤3 保留，更深压平为 `###`；
- 图片抽取：小图内嵌为 `@blob`，大图外置到 `*.res/`；
- 其它样式（字体、颜色、对齐）丢弃并记日志。

## 9. 容错

1. 单行非法不中止文档：未知命令忽略、超长标题降级、空标题降级；
2. 非法 UTF-8 字节替换为 `U+FFFD`；
3. base64 解码失败：该 `@blob` 忽略并告警；
4. 单行 > 1 MB 视为异常，截断并告警。

- [ ] 标题 119/120/121 字节边界：仅 <120 视为标题
